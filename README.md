# 可乐跳跳瓶 · Bottle Jump 3D —— APK 逆向复刻（网页版）

> 从原版 APK（`com.games.bottle.gtx` v1.5.6，Unity 2018.3.14f1 / IL2CPP）中**逐素材提取**还原的横屏网页游戏。
> 所有贴图 / 精灵 / 网格 / 材质 / 音效 / 字体 / 关卡数据均出自 APK 本身，未凭空创作。

## ▶ 运行
```bash
cd game
python3 start_server.py     # 然后浏览器打开 http://127.0.0.1:8899
```
或任意静态服务器：
```bash
cd game && python3 -m http.server 8899
```

## 🖼 界面（对照原版实机视频修正）
- **主菜单**：米色砖墙背景 + BOTTLE JUMP 3D 标题 + 3D 瓶子站在彩色方块上（原版墙纸贴图），左上蓝色齿轮、右上金币数、底部 **ADS / 水瓶开始按钮 / VIP**（广告/会员购买按你的要求剔除，仅保留按钮样式）。
- **游戏内 HUD**：顶部居中**关卡进度条（如 15→16，白色已过/灰色未到）**，左上金币，左下浅蓝圆形暂停按钮；开局显示原版 Tap 提示精灵。
- **瓶子图鉴**：3×3 网格（黄框=已解锁、黑剪影=未解锁），底部「随机解锁 1000 金币」，左上返回、右上金币。

## 🎮 操作
- **点击 / 空格 / ↑**：跳跃（瓶子前空翻）
- **空中再点**：二段跳（每段跳跃最多 2 次踢击，取自原版 `flips=2`）
- **R**：重开本关
- 控制方式为「点一下跳一下」：跳到家具/地板上前进，碰到过高家具侧面会被挡住（此时再跳可翻越），掉出关卡或卡住判定失败。

## 🔬 逆向关键发现（重要更正）
早期会话曾把资产误判为“专有加密/表被置换”，原因是拆包时 1MB 分片（`*.splitN`）被**按字典序**拼接（split0, split1, split10, split11…）导致文件错位。
实际：APK 将大序列化文件切成 1MB 分片（UnityPy 原生按数字序自动合并），**数据本身是标准 Unity 格式、完整可读**。错误拼接消除了后，全部 Mesh/贴图/材质/关卡可 1:1 提取。

## ✅ / ⚠️ 忠实度说明
- **1:1**：所有美术资源、3D 网格几何、材质颜色、关卡组合配方、音频、字体、跳跃/重力/翻转等核心物理数值。
- **已核实**：跳跃实现为 `kickVector × kickPower` 施加刚体初速（反汇编 `GetVelocity` 验证），落地停速/复位跳数（`OnCollisionEnter`），空中重力 `-25.082`（`FixedUpdate`, ForceMode.Acceleration）。
- **近似**：
  1. 原版为 9:19 竖屏，本版按要求改为 **16:9 横屏**（相机改从房间正面取景，fov 42，软件光栅预览校验过构图）。
  2. UI 主菜单/HUD 使用原版精灵与字体手排布局（原版 UI 预制体布局导出任务在设备内存限制下未完成，后续可继续像素级对齐）。
  3. 部分交互规则（撞家具是否致死、卡住判定）基于反汇编+字符串证据推断，未在真机逐项对比。
  4. 广告 / 内购 / VIP 订阅按你的要求**全部剔除**。
